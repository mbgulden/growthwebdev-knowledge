## What to build / refresh next

### 1) Refresh AOT Kailua Beach Park guide
- **Target:** `/oahu-kayaking-and-beach-adventures/ultimate-guide-for-kailua-beach-park-experience-windward-oahus-safest-and-most-adventurous-beach/`
- **Evidence:** KBA’s `/kailua-beach-park` page has the strongest Ubersuggest signal: 179 organic keywords, est. 28,707 traffic, PA 36, 100 backlinks / 72 referring domains. AOT’s corresponding page already has 7,169 impressions but only 0.2% CTR and avg position 9.7.
- **Content angle:** Make it the best practical Kailua Beach Park planning page from a local outfitter: safe swimming, family beach day, kayak/SUP launch logic, wind/parking/restroom notes, and where rentals/tours fit.
- **Acceptance criteria:** Update title/meta/H1/H2; add FAQPage + HowTo; add gear checklist; internally link Kailua kayak rentals, e-bike rentals, SUP/beach gear, Popoia/Flat Island, Mokulua tours; include clear booking CTAs.

### 2) Refresh AOT Lanikai Beach guide + snorkel support
- **Target:** `/oahu-kayaking-and-beach-adventures/ultimate-guide-to-lanikai-beach/ and /activities/lanikai-beach-self-guided-snorkel/`
- **Evidence:** KBA’s `/lanikai` page is focused on Lanikai snorkeling and ranks for “lanikai beach snorkel” at pos 2 (vol 720) plus related snorkeling terms. AOT has Lanikai guide impressions (4,503, avg pos 10.5) and a Lanikai snorkel activity page (937 impressions, avg pos 10.8), but CTR is near-flat.
- **Content angle:** Own the honest local answer: when Lanikai snorkeling is worth it, when Kailua/Popoia/Mokes are better, what gear to bring, and neighborhood-respect logistics.
- **Acceptance criteria:** Update guide and activity copy; add snorkeling FAQ; add “how to do Lanikai without being that visitor” access section; link to e-bike/snorkel adventure, Kailua bike rentals, and Sharks Cove vs Lanikai comparison.

### 3) Strengthen Kailua kayak rental page for commercial intent
- **Target:** `/rentals/oahu-tandem-kayak-rentals/kailua-kayak-rentals/`
- **Evidence:** AOT’s Kailua kayak rental page has 5,496 impressions, 90 clicks, avg position 13.1. Query set includes “kailua kayak rental,” “kayak rentals kailua,” “lanikai kayak rental,” and competitor-brand leakage “kailua beach adventures.”
- **Content angle:** Make the rental page answer the logistics questions KBA spreads across rentals/tours/delivery pages: where to launch, carts/transport, conditions, routes, timing, and which rental fits which paddler.
- **Acceptance criteria:** Add comparison blocks for Popoia/Flat Island vs Mokulua vs Lanikai; tighten title/meta for Kailua + Lanikai kayak rental; add FAQ/Product schema if absent; link guide pages back into this money page.

### 4) Optional new hub: Kailua/Lanikai beach gear logistics
- **Target:** `/oahu-equipment-rentals/kailua-lanikai-beach-gear-rentals/ (candidate)`
- **Evidence:** KBA is building supporting pages for bikes, SUP, lockers, coolers, boogie boards, and delivery. AOT has scattered pages but no obvious “what gear do I need for a Kailua/Lanikai beach day?” hub.
- **Content angle:** Only create if inventory review confirms no existing page can cleanly own beach-day logistics. This should be a practical hub, not a generic blog post.
- **Acceptance criteria:** Cover kayak/SUP/e-bike/snorkel/cooler/chair/umbrella choices, pickup/return logistics, beach etiquette, and strong internal links to rentals/activities.
