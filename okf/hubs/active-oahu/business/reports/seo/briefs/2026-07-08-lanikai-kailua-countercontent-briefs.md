# AOT Counter-Content Briefs — KBA Kailua/Lanikai Territory Alerts

Date: 2026-07-08

## Brief 1 — Fix and relaunch Lanikai snorkel page

### Target URL
`https://activeoahutours.com/activities/lanikai-beach-self-guided-snorkel/`

### Problem
The page is receiving impressions, but the local HTML currently has a mismatched title/body pattern: title says **Lanikai Beach Self-Guided Snorkel Adventure — North Shore**, while the headings/body include Sharks Cove / Pupukea content. That is a relevance and trust leak.

### GSC evidence
- Page: `https://activeoahutours.com/activities/lanikai-beach-self-guided-snorkel/`
- 2026-04-07 → 2026-07-06: 1 click / 911 impressions / 0.1% CTR / avg position 10.9.
- Query opportunity: `lanikai beach snorkeling` — 2 clicks / 488 impressions / 0.4% CTR / avg position 10.5.

### KBA evidence
- KBA page: `http://www.kailuabeachadventures.com/lanikai`
- Ubersuggest: 73 est. traffic, 15 organic keywords.
- Keyword signals: `lanikai beach snorkel` pos 2 / vol 720 / traffic 44; `snorkeling lanikai beach` pos 7 / vol 590 / traffic 13; `lanikai snorkeling` pos 5 / vol 140 / traffic 7.

### Content direction
Rewrite as a real Lanikai snorkel page, not a Sharks Cove clone:
- Lead with when Lanikai snorkeling is good and when it is not.
- Explain sandy entry, shallow reef/patch reef expectations, visibility, wind exposure.
- Explain parking/access honestly; point to e-bike/snorkel combo where relevant.
- Add reef-safe behavior and local-resident respect.
- Add direct CTA for snorkel gear / e-bike + snorkel / beach-day rentals.

### Acceptance criteria
- Title, H1, H2s, body, schema, and CTA all align with Lanikai snorkeling.
- No Sharks Cove / Pupukea route copy remains unless used as a comparison link.
- GSC target queries are included naturally: `lanikai beach snorkeling`, `lanikai snorkeling`, `lanikai beach snorkel`, `snorkel rentals kailua`.

## Brief 2 — Kailua + Lanikai beach-day rental hub

### Target URL
Prefer refreshing/expanding:
`https://activeoahutours.com/beach-gear-rentals/`

Potential supporting new route if needed:
`/kailua-lanikai-beach-day-rentals/`

### Problem
KBA is bundling beach-day intent into a Day Pass page. AOT already has a beach gear page with strong rental inventory, but the current opportunity is to frame it as a complete Windward beach day, not just itemized gear.

### GSC evidence
- `kailua beach park`: 8 clicks / 2,570 impressions / 0.3% CTR / avg position 10.0.
- `kailua beach`: 4 clicks / 2,350 impressions / 0.2% CTR / avg position 7.9.

### KBA evidence
- KBA page: `http://www.kailuabeachadventures.com/daypass`
- Ubersuggest: 73 est. traffic, 29 organic keywords.
- Keyword signal: `lanikai beach park` pos 8 / vol 210 / traffic 6.
- Page headings: “epic day at kailua beach,” “All Access to Beach Gear and Facilities by Lanikai and Kailua Beach Park,” snorkeling + bicycling + body boarding + chair/umbrella.

### Content direction
Create/refresh copy around:
- “Plan a Kailua or Lanikai beach day without hauling gear from Waikīkī.”
- What to rent by beach type: Kailua = easy facilities; Lanikai = beautiful but parking-limited; Bellows/Waimānalo where appropriate.
- Gear bundles: snorkel set + chairs + umbrella + cooler + bodyboard.
- Pickup/return logistics, multi-day value, and after-beach flexibility.
- Internal links to Lanikai guide, Kailua Beach Park guide, snorkel rentals, chair rentals, umbrella rentals.

### Acceptance criteria
- Add a dedicated beach-day section above the fold or near pricing.
- Include clear rental package CTAs.
- Add FAQPage schema for parking, Lanikai gear use, chairs/umbrellas, and snorkel safety.
