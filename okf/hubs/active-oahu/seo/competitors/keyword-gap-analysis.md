## Strategic gap clusters (where AOT has zero or weak presence)

### Cluster 1: Geographic brand queries (Kailua + Lanikai + Waimanalo)

KBA owns these because they have mega-pillar guides.

**AOT's opportunity:**
- `/guides/lanikai-beach-guide/` (BRIEF in Tier 1, BRIEF-005 nearby)
- `/guides/kailua-beach-park-guide/` (currently weak)
- `/guides/waimanalo-beach-guide/` (BRIEF-001, tier 1 priority)

### Cluster 2: Sea turtles + marine life

Surfnsea has "Where to See Turtles on Oahu" (962 visits/mo). AOT has nothing.

**AOT's opportunity:** NEW PAGE — `/guides/sea-turtles-oahu/`
- Own the Sharks Cove → turtle viewing angle
- Photos from the 14,490 library
- Operator voice + ethical viewing practices

### Cluster 3: North Shore snorkeling (overlap with HBT + Surfnsea)

HBT: "Oahu's North Shore Snorkeling" (983 visits/mo)
Surfnsea: "Sharks Cove Guide" (96 visits/mo)
AOT: Sharks Cove page gets 589 real clicks (from GSC) — **AOT IS WINNING HERE**

**AOT's opportunity:** Maintain dominance by adding more depth to Sharks Cove page (currently ranks pos 6.1 — push to top 3).

### Cluster 4: Best X / Top 10 (commercial intent)

LoveOahu + KBA both dominate "best beaches oahu", "best snorkel oahu" type queries.

**AOT's opportunity:** Pillar page at `/guides/best-beaches-windward-oahu/` (BRIEF-009) + `/guides/best-snorkeling-oahu/` (new).

### Cluster 5: Pillar location guides (KBA pattern)

KBA has 2,000-5,000 word pillar guides for each major location. AOT doesn't.

**AOT's opportunity:** Build out pillar pages for each major location:
- Lanikai (4,000 words)
- Kailua Beach Park (3,000 words)
- Waimanalo (3,500 words — BRIEF-001)
- Chinaman's Hat (2,500 words)
- Mokulua Islands (3,000 words)
- Sharks Cove / North Shore (4,000 words)

### Cluster 6: "Near me" queries (voice search)

153 queries with "near me" in them. AOT has minimal near-me pages.

**AOT's opportunity:** Create `/near-me/` pages for each major activity:
- `/near-me/kayak-rental-near-me/`
- `/near-me/snorkel-rental-near-me/`
- `/near-me/paddleboard-rental-near-me/`
- `/near-me/e-bike-rental-near-me/`

With LocalBusiness schema + geo-coordinates.
