## Root cause (now understood)

The error `Some requested scopes were invalid. invalid=[analytics.readonly]` means the **OAuth client itself doesn't have analytics.readonly in its scope allowlist**. This is **separate** from:

- ❌ GCP project API library (which you enabled)
- ❌ OAuth consent screen "Scopes for Google APIs" (which you added it to)
- ✅ **OAuth CLIENT's scope allowlist** — this is set when the OAuth client is created

This third setting (the OAuth client's allowlist) is **only modifiable via the GCP Console UI** when creating or editing the OAuth client. I (Kai) cannot modify it programmatically — it requires a human to:
1. Open GCP Console → APIs & Services → Credentials
2. Click the OAuth client `977861670312-8prttldh1prmgf1h0pguld5boa3g022h.apps.googleusercontent.com`
3. Click "Edit"
4. Scroll to "API restrictions" section
5. Either remove the restriction (recommended) or explicitly add `analytics.readonly` to allowed scopes
6. Save

OR alternatively, create a new OAuth client with no API restrictions and use that client ID.

## Why this matters

The error message "valid=[...] invalid=[analytics.readonly]" is **Google's OAuth server** saying: "I know about this scope, but the OAuth client you're using isn't allowed to request it." The OAuth client ID itself needs updating.
