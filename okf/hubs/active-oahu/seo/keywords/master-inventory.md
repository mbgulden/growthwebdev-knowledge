## Use this inventory

### For Ella (content writer)
When writing or refreshing a page, look up the cluster for that page. Each keyword in the cluster should be:
- **Mentioned in the title or H1** (when relevant and natural)
- **Used in at least 2 subheadings**
- **In the meta description** (1x)
- **In the URL slug** (for the page itself, when creating new pages)
- **In image alt text** for primary images

### For Kai-CSS (technical SEO)
- Check that the target page has the right schema (LocalBusiness, TouristTrip, FAQPage, HowTo)
- Verify internal links from cluster-hub pages point to spoke pages
- Validate page is mobile-friendly and loads in <3s

### For Kai (analytics + automation)
- Track ranking changes per cluster, not per keyword
- When a cluster shows growth, escalate content production for that cluster
- When a cluster stagnates, run a fresh SERP analysis to find new opportunities

### For AGY (research)
- Use this as the seed list for any new keyword expansion
- When researching competitors (KBA, HBT, Surfnsea), focus on clusters where AOT has the biggest gap
- Identify "missing keywords" — high-volume queries that don't yet appear in any cluster
