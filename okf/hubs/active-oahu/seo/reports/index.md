# AOT SEO Reports

Auto-generated reports from the cron stack. Each report has a JSON (machine-readable) and MD (human-readable) version.

## Daily reports

| Report | Cron | Output filename pattern | Generated by |
|---|---|---|---|
| Daily rank tracker | 06:00 UTC | `daily-rank-YYYY-MM-DD.{json,md}` | `rank_tracker.py` |
| Daily broken-link scan | 06:30 UTC | appended to `broken-links.md` | `broken_link_checker.py` |
