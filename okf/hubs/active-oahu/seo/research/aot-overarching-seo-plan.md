## Executive Summary
This master plan outlines the strategic transition of Active Oahu Tours (AOT) from traditional search engine optimization (SEO) to a dual-pronged **Generative Engine Optimization (GEO)** and **Answer Engine Optimization (AEO)** model. With the rise of Google AI Overviews, Perplexity, and ChatGPT, discovery in the tourism sector has decoupled from raw website clicks. Travelers now make decisions based on synthesized search summaries upstream. 

By leveraging AOT's physical co-location with Hawaiian Watersports at 134B Hamakua Dr., Kailua, and integrating the 2.5 TB Google Drive media library, AOT will capture high-intent travelers through **Stat Density**, **Information Gain**, and **AEO Quick Answer Blocks**. This plan provides a detailed breakdown of core revenue pages, keyword clusters, 25 high-impact content opportunities, technical blockers, internal linking, schema markup, and a role-based Linear task list to enable autonomous execution.

## 1. SEO North-Star & Revenue Pages

### The SEO North-Star
Establish Active Oahu Tours as the **undisputed local authority** for outdoor adventures in Windward Oahu (Kailua, Lanikai, and Waimanalo) across traditional SERPs and generative AI models. 

The strategy focuses on:
*   **Information Gain (IG):** Injecting proprietary, citable data (wind speeds, water visibility, municipal laws) to displace the generic "Consensus Baseline" of competitors.
*   **High-Ticket Conversion:** Transitioning from thin-margin, single-item kayak rentals to high-margin, multi-activity packages ("Adventure Passports" combining E-Bikes, guided Mokulua paddling, and HWS E-Foiling).
*   **Eco-Tourism (Mālama Hawaiʻi):** Promoting environmental conservation (beach cleanup discounts) to align with state regulations and appeal to U.S. West Coast travelers.
*   **Younger Japanese Travelers:** Targeting independent Japanese honeymooners/travelers, bypassing KBA’s dominance in standard bus-tour walk-ins.

### Core Revenue Pages (The Money Path)
1.  **`/tours/` (Guided Tours Landing Page):** Central conversion hub for E-Bike and guided kayak tours.
2.  **`/rentals/` (Equipment Rentals Landing Page):** E-Bikes, beach gear, and self-guided rental portals.
3.  **`/rentals/explorer-oahu-kayak-rental-package/`:** High-margin self-guided package including paddles, life vests, dry bags, soft car racks, and site delivery.
4.  **`/activities/guided-mokulua-islands-kayak-tour-and-e-bike-adventure/`:** Premium combo tour ($200+ ticket size).
5.  **`/activities/chinamans-hat-self-guided-oahu-kayak-tour/`:** High-volume self-guided kayak destination page.
6.  **`/activities/popoia-island-and-kailua-bay-guided-kayak-tour/`:** Guided beginner-friendly tour to Flat Island.
7.  **`/activities/sharks-cove-self-guided-snorkel/`:** Main snorkeling traffic vector.
8.  **`/activities/kailua-e-bike-kau-kau-guided-adventure/`:** High-intent food and adventure e-bike tour.
9.  **`/ja/` (Japanese Landing Page):** Tailored guides emphasizing independent exploration and guided packages for Japanese tourists.

*   **Target Queries:** `Oahu kayaking safety`, `Kailua Bay wind patterns`, `Mokulua Islands paddling difficulty`, `Waimanalo Beach swimming safety`, `how to transport kayaks Oahu`.

## 4. Technical SEO Blockers

Based on code-level audits of the static mirror repository and deployment, the following 10 critical issues must be resolved to prevent search engine indexing drops and performance regression:

1.  **Exposed WordPress REST API Links (Critical):** Over 120 static pages contain HTML headers linking to the live site's REST API endpoint (e.g. `activeoahutours.com/wp-json/wp/v2/pages/XXXX`). This leaks page IDs and WP structures to security vulnerability scanners.
2.  **Broken 404 Routing / SPA Fallback Override (Critical):** Non-existent URLs on the mirror initially returned `HTTP 200` with the homepage HTML instead of a `HTTP 404` status code. This will result in indexation of soft 404 pages and duplicate content penalties.
3.  **Broken PHP Animation Include in 404.html (High):** The static 404 error page contains a raw iframe pointing to `/wp-content/themes/activeoahu/template-parts/kayak-animation/kayakers.php`. This fails to execute or render in static mode.
4.  **Massive Inline CSS Bloat (High):** The `_templates/head.html` template inlines **108 KB of CSS** (Kadence blocks, theme styles, layouts) directly into *every single page*. This prevents browser caching and severely degrades mobile performance scores.
5.  **Exposed Outdated SEO Plugin Comments (Medium):** All pages contain Yoast SEO Premium v3.8 comments (dating back to 2020) and Site Kit v1.179 comments. This leaks software versions and compromises code cleanlines.
6.  **Broken Search Widget on 404 Page (High):** The search form on the 404 error page is hardcoded to post queries to `/?s=QUERY`. Statically, this triggers the `_redirects` catch-all route, redirecting the user right back to the 404 page in a loop.
7.  **Unoptimized Media Formats & File Sizes (Medium):** Over 1,885 raster images (JPGs/PNGs) are loaded without WebP compression. Several images exceed **1.5 MB** (e.g., `IMG_3867-scaled.jpg`), which significantly degrades mobile page load times.
8.  **Broken Canonical URLs on Deep Sub-Pages (High):** Several sub-pages (e.g. Sharks Cove, Contact, oahu-tour-packages) have broken or relative canonical tags pointing to `index.html` or `../contact-us.html` instead of absolute production URLs.
9.  **Gravity Forms Button Cleanup (Low):** While Gravity Forms scripts were removed, the button elements still retain the WP class `<button class="gform_button button">`, which conflicts with the clean static code.
10. **Ghost Pages with 0 Internal Links (High):** Approximately **114 out of 155 pages (73% of the site)** have zero incoming links from other pages. Crawlers cannot discover these pages organically unless they are mapped in the sitemap.

### Linking Directions & Anchor Text Rules
*   **Downward (Pillar ➔ Hubs ➔ Spokes):**
    *   The Pillar Page must link to the 3 Location Hubs using descriptive anchors: `Kailua Beach Park Guide`, `Lanikai Beach Guide`, `Waimanalo Beach Guide`.
    *   Hubs must link to their respective Spokes using long-tail anchors: `Kailua Beach parking guide`, `Lanikai Beach parking rules`, `Waimanalo Beach swimming safety`.
*   **Upward (Spokes ➔ Hubs ➔ Pillar):**
    *   Every Spoke page must link back to its parent Location Hub and the Master Pillar in the first **150 words** of the body text (e.g. *"...before heading out, consult our [Lanikai Beach Guide](/guides/lanikai-beach-guide/) or view our map of the [best Windward Oahu beaches](/guides/best-beaches-windward-oahu/) to plan your day."*).
*   **Cross-Cluster Interlinking:**
    *   The `Lanikai vs. Kailua Beach` comparison page acts as a bridge, linking directly to both hubs.
    *   Spokes with shared themes (e.g., parking) must link to each other: *“If Lanikai parking is full, head 5 minutes north and check our [Kailua Beach parking guide](/guides/kailua-beach-parking/).”*
*   **Commercial CTAs (Conversion Routing):**
    *   **Kailua/Lanikai Pages:** Must feature prominent CTAs linking to `/rentals/kayak-rentals/` using exact-match anchor text: `Kailua kayak rentals` or `kayak rentals for Lanikai Beach`.
    *   **Waimanalo Pages:** Must explicitly state that *commercial delivery of rental kayaks to the beach is illegal in Waimanalo*. Force users to the physical storefront pickup via CTA: `pick up kayak rentals from our storefront` or `rent beach gear in Kailua`.
