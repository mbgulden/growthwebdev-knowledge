# OKF trust doctrine integration — 2026-07-19

## Session learning

When Michael asks to align Prismatic positioning with OKF/North Star docs, do not frame the product as merely an agent dispatcher, Claude Code competitor, Hermes plugin, or review-agent wrapper. The durable class-level doctrine is:

```text
Claude Code writes work.
Hermes runs agents/tools/plugins.
Prismatic governs work.
```

Prismatic exists because AI agent output is becoming cheap, but trustworthy AI work is still expensive. The OKF should make this explicit so future agents understand what the system is/will-be.

## OKF shape to preserve

Upgrade OKF framing from:

```text
Objective → Key Result → Function → Evidence
```

to:

```text
Objective → Key Result → Function → Evidence → Promotion Decision
```

A workflow is not North-Star complete just because an agent/plugin produced output. It is complete when Prismatic can show evidence needed to trust, reject, approve, publish, export, merge, or safely defer that output.

## Successful Prismatic Engine definition

A successful Prismatic Engine turns agent, plugin, tool, and operator output into decisionable records:

```text
task/event/operator request
→ assigned agent/plugin/tool/operator action
→ standardized completed-work packet
→ proof logs and artifacts
→ provenance and audit events
→ policy/approval gate
→ dashboard/API/task-manager visibility
→ promotion decision
→ durable history
```

## Trust-building doctrine

Do not let “adversarial review agent” become the whole trust story. A review agent can contribute, but trust should be cumulative and system-built:

- packet validation
- changed-file/scope checks
- proof logs
- artifacts
- provenance
- policy decisions
- review state
- dashboard visibility
- promotion history
- explicit non-claims

## Recommended OKF rows/class

Add or preserve a Trust-building OKF map with rows for:

1. Agent output becomes trustworthy via shared completed-work packet validation.
2. Trust is system-built, not review-agent-only.
3. Integration decisions are explicit through promotion states.
4. Evidence survives chat/session context in durable stores.
5. Unsafe work fails closed when proof/scope/policy is missing or ambiguous.

## Key phrase

> Prismatic is not the worker. Prismatic is the work-trust layer.
