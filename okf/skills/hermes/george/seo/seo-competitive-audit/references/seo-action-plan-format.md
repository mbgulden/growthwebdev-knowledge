# SEO Action Plan — Report Compilation Pattern

After a full competitive sweep completes, compile the raw JSON + summary into a structured action plan document. This is a stand-alone deliverable that the client/project owner can use immediately.

## Template Structure

### 1. Starting Position Table
Show where you stand vs competitors: keyword count, DA, traffic, backlinks, referring domains. One honest sentence about the competitive reality.

### 2. Priority Matrix (Ranked)
Two tables:
- **High Impact / Low Effort** — things to do THIS WEEK
- **High Impact / Medium Effort** — things to do THIS MONTH
- **Medium Impact / High Effort** — things to do THIS QUARTER

Each row: action, target keyword/page, expected metric gain, effort estimate.

### 3. Territory Battle Plan
Group pages by geography/theme. For each territory:
- The competitive reality (who owns what, where KBA has zero presence)
- Specific pages to create, with target keyword, volume, position target, and page type
- Whether an interview recording is needed first

### 4. Technical SEO Checklist
Must-fix items (broken pages, missing schema, missing author bylines) vs nice-to-have items.

### 5. Content Pipeline Status
Table showing: interview script → questions written → pages unlocked → recording status (written vs needs recording).

### 6. 90-Day Targets
Month-by-month: deliverables in, traffic targets out. Be realistic but ambitious.

### 7. Monitoring Baseline
The current snapshot of top keywords by traffic, with a note about what to improve and by how much.

### 8. Immediate Next Steps
3-5 concrete actions, assigned to specific people (Michael, Ella, Kai).

## Key Principles

- **Territory-first, not keyword-first.** Group by geography, not by search volume. Visitors search for places, not abstractions.
- **Honest about competitive reality.** If KBA owns #1 and has DA 32, don't say "we'll beat them." Say "take uncontested territory first."
- **Each table must have a takeaway sentence.** Don't just present data — interpret it.
- **Time-box everything.** "Do this week" vs "this month" vs "this quarter" — without deadlines, plans get shelved.
