# HDE email-session branch/worktree cleanup — 2026-07

Use this as a concrete HDE cleanup example after an active feature session that produced verified commits and left many task worktrees behind.

## What happened

After restoring and theming HDE transactional emails, Michael explicitly approved cleanup: “Make sure to clean up any branches and worktrees for Human design engine. The email looks good.”

Cleanup covered multiple HDE-adjacent repos:

- `/home/ubuntu/work/hd-platform`
- `/home/ubuntu/work/hd-platform-staging`
- `/home/ubuntu/work/hd-bodygraph`
- `/home/ubuntu/work/OpenHumanDesignMCP`

## Pattern that worked

1. **Load worktree hygiene first.** Treat cleanup as destructive until proven otherwise.
2. **Inventory all HDE repos before mutation.** Capture, for each repo:
   - `git status --short --branch`
   - `git worktree list --porcelain`
   - local branches with upstream/date/subject
   - current branch and HEAD
3. **Create an archive/manifest before removing anything.** Use timestamped archive path outside the repo, e.g. `/home/ubuntu/work/_hde_cleanup_archive/<timestamp>/`, with:
   - `manifest.json`
   - `manifest.txt`
   - `removed.json`
   - `branch_cleanup.json`
   - final worktree list
4. **Classify conservatively.**
   - Canonical checkouts stay.
   - Clean non-canonical worktrees with upstream branches can be removed while preserving branches/remotes.
   - Dirty/non-canonical worktrees get archived before removal.
   - Current, dirty, local-only, or unmerged branches are preserved.
5. **Archive dirty/untracked state before removing dirty temp worktrees.** For each dirty/ambiguous worktree, save:
   - `head.txt`
   - `branch.txt`
   - `status.txt`
   - `diff.patch`
   - `staged.patch`
   - `untracked-files.txt`
   - bounded `untracked.tar.gz`
6. **Do not delete remote refs by default.** User asked for branches/worktrees, but review history should remain unless remote branch deletion is explicitly approved.
7. **Local branch deletion rule.** Delete local branches only when mechanically safe:
   - exact copy of upstream, or
   - already merged to intended base.
   Preserve local-only/unmerged branches.
8. **Check for late-discovered worktrees after branch deletion failures.** If `git branch -D <branch>` fails with “used by worktree at …”, inspect that worktree, remove it only if clean/safe, then retry local branch deletion.
9. **Clean verification-generated bytecode dirt.** After Python verifiers/imports, remove or restore `__pycache__` dirt; do not confuse that with user work.
10. **Verify with `/tmp/hermes-verify-*`.** The verifier should assert:
    - archive manifests exist,
    - removed worktree paths are gone from disk,
    - removed worktrees are gone from `git worktree list --porcelain`,
    - local deleted branches are absent,
    - representative remote refs still exist,
    - verification-generated bytecode dirt is gone,
    - temp verifier file is cleaned.

## Important caveats

- Dirty/live app checkouts were preserved, not “cleaned” into oblivion.
- Staging feature branch ahead of remote was preserved.
- Runtime backup directories in the active staging checkout were not silently deleted.
- Remote review branches were preserved.
